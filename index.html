A note on accuracy

NetMeter measures the path between this browser and a nearby Cloudflare edge. It is a useful snapshot, not a laboratory measurement or a guarantee of the speed to every website.

Test traffic goes to Cloudflare's public speed endpoints. NetMeter does not run a server. Saved results stay in this browser's local storage.
